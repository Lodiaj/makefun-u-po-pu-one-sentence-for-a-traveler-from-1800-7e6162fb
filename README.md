One sentence explaining the modern internet to a traveler from 1800, built only from things that traveler would already know: every library, post office and market in the world joined by invisible roads, so any letter arrives anywhere in a blink and any book opens at your table. `main.ts` validates the sentence (single line, at most 200 characters, printable ASCII, no word coined after 1800, anchored on a familiar thing) and writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
